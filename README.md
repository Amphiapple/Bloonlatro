# Bloonlatro v0.5.0

A Balatro mod that incorporates Bloons Tower Defense into the base game

# New Additions:

Upgrading towers has finally arrived! Open Upgrade packs to find Upgrade cards that will upgrade your towers to a higher tier!

Currently, Bosses do not work in the lastest versions of Steammodded. Use Steammodded v1.1814 in order to access Boss challenges.
